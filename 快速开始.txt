会译字幕 · MeetSub 1.1.0
==========================

1. 双击 MeetSub.exe 启动。
2. 点击「开始实时字幕」。应用会自动捕获电脑正在播放的会议声音。
3. 字幕出现在屏幕底部；拖动移动，右键更多，Ctrl+滚轮改字号。
4. 全程本地识别与翻译（默认高精度 Qwen2.5-1.5B），音频与文字都不上传。

首次使用
--------
- 便携包已包含默认离线模型（small.en + Qwen2.5-1.5B），联网不是必需的。
- 如果模型缺失，应用会提示「准备模型」，点击即可从 hf-mirror 下载。
- 高精度模式启动/预热约 10 秒，翻译每句约多 1–2 秒；追求低延迟可在设置里切到 M2M100 或 OPUS-MT。
- 设置 → 翻译里可填「会议背景」和「术语表」，对 Qwen/在线翻译准确率提升明显。
- Windows 10 需要 2004 或更新版本才能使用「屏幕共享时隐藏字幕」。

常用操作
--------
- 暂停：暂停会停止捕获系统声音，继续后恢复。
- 收起：隐藏到系统托盘，字幕与记录继续；双击托盘图标恢复。
- 保存记录：主窗口「保存记录」，或托盘菜单。
- 记录目录：文档\MeetSub\transcripts
- 设置：字体、字号、颜色、宽度、位置、模型、翻译方式、防录屏。

隐私
----
- 系统音频只在本机处理，不写入音频文件，不上传。
- 默认 Qwen2.5 本地 LLM 翻译：完全不上传。
- 如主动选择在线翻译，只发送识别后的英文文字，不发送音频。
- API Key 使用 Windows DPAPI 加密保存。
- 字幕窗口默认对常规屏幕共享/录屏隐藏（防录屏）。
- 无遥测、无账号。

故障处理
--------
- 没有字幕：检查设置的输出设备，确认会议声音从本机扬声器/耳机播放。
- 没有中文：设置 → 翻译 → 测试翻译，检查离线模型或 API 密钥。
- 延迟高：改用 base.en + OPUS-MT，或降低「停顿定稿」时间。
- 详细说明见 README.md。
