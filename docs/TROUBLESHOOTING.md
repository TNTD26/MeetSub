# 故障排查

> 先看日志：`%LOCALAPPDATA%\MeetSub\logs\meetsub.log`。日志只记录设备、耗时、错误，
> **不写会议文本**，可以直接贴出来求助。

## 开始后没有字幕

按顺序检查：

1. **会议声音真的在本机播放吗？** 软件捕获的是「电脑正在播放的声音」，不是麦克风。
   如果声音来自另一台电脑、手机或会议室音箱，本机没有可捕获的音频流。
2. **输出设备对不对？** 「设置 → 音频与识别 → 输出设备」保持「自动」时会跟随 Windows
   默认输出；蓝牙耳机常同时存在「通话 / 音乐」两个端点，切换过设备后建议手动选一次
   （列表里带 `[Loopback]` 的那一项）。
3. **会议软件是否用了独占模式？** 部分播放器/会议软件的「独占模式」输出会让回环采集
   拿到静音。
4. **模型是否就绪？** 主窗口底部会提示模型状态；`small.en` 与翻译模型都显示「已就绪」
   才会出中文。
5. **系统音量是否静音？** 系统静音时回环流同样静音。

仍无声音时，先播放任意网页视频测试，排除会议软件本身的问题。

## 有英文字幕，但没有中文

- **本地翻译**：确认所选模型已下载（设置 → 翻译会显示「已就绪（约 xxx MB）」）。
  Qwen2.5 约 1490 MB，M2M100 约 470 MB，OPUS-MT 约 152 MB。
- **在线翻译**：确认接口地址、模型名、API Key 有效，点「测试翻译」看具体报错。
  接口必须使用 HTTPS；只有 `127.0.0.1` / `localhost` 的本机 Ollama 允许 HTTP。
- **看主窗口右上角**：翻译失败会在这里给出原因（超时、鉴权失败、模型缺失等）。
- Qwen 首句可能要多等 1–2 秒预热，属正常现象。

## 字幕延迟偏大

| 手段 | 效果 |
| --- | --- |
| 识别模型 `small.en` → `base.en` / `tiny.en` | 最大，准确度下降 |
| 翻译切 M2M100 或 OPUS-MT | 省掉 LLM 每句 1–2 秒 |
| 「停顿定稿」650 ms → 450–550 ms | 更早断句，片段更碎 |
| 翻译切在线 DeepSeek / OpenAI | 通常更快更准，但要联网 |
| 关闭其他吃 CPU 的程序 | Qwen 与 Whisper 会抢同一批核心 |

## 字幕窗口不见了

- 主窗口点「隐藏字幕」恢复；
- 托盘图标右键 → 显示字幕；
- 如果开了「鼠标穿透」，只能从主窗口或托盘关掉它；
- 双显示器切换后位置可能落到已断开的屏幕上，改「设置 → 字幕外观 → 位置 → 底部」再保存。

## 屏幕共享里仍然能看到字幕

- 确认「设置 → 字幕外观 → 屏幕共享/录屏时隐藏字幕」已勾选（默认开启）。
- 该功能依赖 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，需要 **Windows 10 2004+**，
  老系统或部分虚拟显示器/采集卡不支持。
- **拍屏、硬件采集卡、手机拍屏幕无法被系统 API 拦截**，这不是 bug。

## 退出/重启后没有记录

- 确认「设置 → 记录与隐私 → 开始字幕后自动保存」已勾选；
- 也可以随时点主窗口「保存记录」手动落盘；
- 默认目录 `文档\MeetSub\transcripts`，权限异常时换一个可写目录；
- 每次翻译完成都会原子写入，异常退出最多丢当前句。

## 模型下载失败 / 太慢

- 默认源是 `https://hf-mirror.com`，可在「设置 → 音频与识别 → 模型源」切到官方
  `https://huggingface.co`。
- 命令行下载（支持断点续传）：

  ```powershell
  .\.venv\Scripts\python.exe scripts\download_models.py --all
  ```

- 只装了部分模型也能启动，应用会提示缺失项；用不到的翻译方案可以不下载。

## 启动很慢 / 内存占用高

- 首次开始字幕要加载并预热 Whisper 与 Qwen，约 9–13 秒；之后开始会快很多。
- 默认加载后常驻约 2–2.8 GB（small.en + Qwen2.5）。8 GB 内存机器请改用
  `base.en` + M2M100/OPUS-MT，或在「设置 → 翻译」选在线接口。

## 双击没反应 / 又开了一个窗口

- 应用只允许单实例，重复启动会唤醒已运行的窗口（可能藏在托盘里）。
- 便携版首次运行被 SmartScreen 拦截时，选「更多信息 → 仍要运行」。
- 提示缺少 `VCRUNTIME140_1.dll` 时安装
  [VC++ 2015–2022 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
